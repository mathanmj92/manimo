Manimo — interface options

Aim: someone who has never opened a code editor can go from an idea to a narrated video without reading help. Three layouts first, then three ways to open Settings. They are static mock-ups — pick one of each and I will build it.

What is hard for a first-time user today

The top bar has many buttons of equal weight; the order of work (write, render, narrate, share) is not shown; quality, voice, AI and folder choices live in different places; and technical words (engine, preset, fps) show up early.

Layout options

The Settings button (right side)

Today it opens a long dialog with technical wording. Three better ways, shown inside layout A.

My suggestion: A (Guided steps) + S1 (side drawer), with S2's quick menu as the gear's first click.
It keeps the code-left, video-right layout you already like, adds the step bar so nobody wonders what to do next, and moves every technical choice into one calm drawer. “Ask AI” and “Narrate” become steps instead of extra buttons.
