How to use Manimo

Manimo turns animation code into video. You never need to touch Python: paste code, press one button, watch it play.

  1. Add your code

    Paste it, open a .py file (File → Open), load an example (File → Examples), or press Ask AI and describe the animation in your own words. Manimo understands both ManimGX code and Manim code.

  2. Choose what to render

    If your file has several scenes, pick one in the Scene menu, or choose All scenes to render them one after another.

  3. Pick the quality

    Click the quality button. Use 480p for quick drafts and 1080p for the finished video.

  4. Press Start Rendering

    Progress shows under your code. When it finishes, the video plays in the Preview on the right.

  5. Find your video

    Videos are saved in the folder shown in the toolbar (by default Videos\Manimo). Click the arrow beside it to open the folder.

Handy to know

Hover for help
Rest the mouse on a word or number in the code. A small note says what it does and what to try changing.
Parts strip
Under the preview, one button per next_section in your code. Click one to jump to that part.
AI assistant
Press the sparkle icon in the top bar (or Ctrl+L) to open the assistant, connect an AI once, then describe an idea. It writes the code, checks it for errors and overlapping text, fixes what it finds, and you press Apply & render.
Present
Renders one scene as a slideshow that pauses at each section. Great for lectures.
Layout notes
After a render, click a note to jump to the line it talks about. They are hints, not errors.
Sessions
Manimo remembers your work when you close it. Session → Save lets you keep a named copy.
Add Manim
Settings → Engines. One click downloads Manim so you can render from manim import * code too. Or tick Manim Community Edition and LaTeX when you run the Manimo installer: it brings both, with no download.

Keyboard shortcuts

Something not working?

Start Rendering does nothing

Hover the button or look under the code: it says what is missing, usually a scene class. Your code needs a class that ends in Scene, for example class Hello(m.Scene).

"This code is written for Manim, which is not installed"

Open Settings and press Add Manim under Engines. It needs the internet once. To avoid the download, run the Manimo installer again and tick Manim Community Edition and LaTeX.

The assistant says "add your API key"

Press Connect an AI in the assistant panel. You need a key from your AI service, for example a Claude API key from console.anthropic.com. Using it costs a small amount per request and is billed by that service, not by Manimo.

Is my code sent anywhere?

Only when you use the assistant, and only to the service you connected. Rendering, editing and everything else stay on this computer.

The video is large

Choose a lower quality, or "Smallest file" under Video encoding in Settings.

I want to report a problem

Open Help → Report a problem, say what happened, then copy the report or save it as a file and send it to the author. It includes your setup details, so the problem is easier to find.

      What Manimo adds

      Projects
      File → New project keeps every scene, render and recording of a lesson in one folder with a project.mo file. Reopen it from File → Recent projects. The Project panel (folder icon, top left) shows which scenes are out of date and renders only those.
      Compose
      Press Compose in the top bar. A pop-up editor opens with every video you rendered in the project already on the timeline. Cut, trim, fade, add background music, record yourself on camera or a voice-over, then export one finished video with chapters and subtitles.
      Ask AI
      Describe an animation and the assistant writes and checks the code (Ctrl+L).
      Present
      Plays a scene as slides that pause at each next_section.
      Script
      Lists every narrated line with its time. Save as .txt, .srt, .vtt or .json, and pick the voice.
      Narrate
      Record your own voice (and camera) over a finished video and save it as a new file.
      self.say(…)
      Speaks a sentence with the built-in voice. with self.voiceover(text="…") from other Manim code also works.

      Videos and documentation

      These open in your web browser. Video links open a YouTube search, so you always get the current videos.

      Report a problem

      Tell us what went wrong. Manimo adds details about your setup so the problem is easier to find. Nothing is sent until you press Send by email: it opens your email app with the report ready to send to mathannits92@gmail.com. You can read the whole report below first.
